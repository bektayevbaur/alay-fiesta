# ALAY Fiesta 2026

Сайт новогоднего корпоратива ALAY Pro Runner «Испания»: 25 декабря 2026, 18:00, «Ухо и Медведь», Курмангазы 107.

- `index.html` — приглашение, живой отсчёт (по времени Алматы) и форма регистрации.
- `budget.html` — прогноз бюджета и факт по оплатам. На главной ссылки на неё нет, поисковики её не индексируют.
- `config.js` — адрес Google Apps Script, куда уходят заявки.
- `apps-script/Code.gs` — код для Google Таблицы.

Заявки попадают в Google Таблицу. Оплата отмечается там галочкой в колонке «Оплатил ✓». Сайт показывает наружу только количество записавшихся, без имён и телефонов.

## Запуск по шагам

### Шаг 1. Google Таблица (5 минут)

1. Откройте https://sheets.new и назовите таблицу, например «ALAY Fiesta — заявки».
2. Меню **Расширения → Apps Script**.
3. Удалите всё в файле `Code.gs` и вставьте код из `apps-script/Code.gs` этого репозитория. Нажмите 💾 **Сохранить**.
4. Вверху выберите функцию **setup** и нажмите **▶ Выполнить**.
5. Google попросит разрешение: **Проверить разрешения** → ваш аккаунт → **Дополнительные настройки** → **Перейти на страницу проекта (небезопасно)** → **Разрешить**. Это ваш собственный скрипт, а предупреждение стандартное.
6. Вернитесь в таблицу: появится лист «Заявки» с красной шапкой и галочками.

### Шаг 2. Опубликовать скрипт

1. В Apps Script справа вверху: **Начать развертывание → Новое развертывание**.
2. Шестерёнка ⚙ → **Веб-приложение**.
3. «Запуск от имени»: **Я**. «У кого есть доступ»: **Все**.
4. **Развернуть** и скопируйте **URL веб-приложения** (заканчивается на `/exec`).

### Шаг 3. Вставить адрес в сайт

1. Откройте в репозитории файл `config.js` и нажмите ✏️ (Edit).
2. Вставьте адрес в кавычки: `scriptUrl: "https://script.google.com/macros/s/.../exec"`.
3. **Commit changes**.

### Шаг 4. Включить GitHub Pages

1. В репозитории: **Settings → Pages**.
2. «Source»: **Deploy from a branch**. «Branch»: **main**, папка **/ (root)** → **Save**.
3. Через 1–2 минуты сайт откроется по адресу https://bektayevbaur.github.io/alay-fiesta/

### Шаг 5. Проверить

1. Откройте сайт, заполните форму на себя и нажмите «Я в деле!».
2. В таблице должна появиться строка. Поставьте галочку «Оплатил ✓»: строка станет зелёной.
3. Откройте https://bektayevbaur.github.io/alay-fiesta/budget.html и нажмите «Обновить данные»: цифры подтянутся из таблицы.
4. Удалите тестовую строку и киньте ссылку на сайт в чат.

## Если что-то поменяли в скрипте

После правки кода в Apps Script: **Начать развертывание → Управление развертываниями → ✏️ → Версия: Новая версия → Развернуть**. Адрес при этом не меняется.
